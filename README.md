# Website-using-HTML-and-CSS-
A simple beginner friendly website made using HTML5 and CSS3
****
**🚗 LuxDrive – Luxury Car Dealership Website**<br><br>
LuxDrive is a static frontend web project developed using HTML5 and CSS3 that simulates a premium luxury car dealership website.<br>
The project focuses on responsive design, modern UI aesthetics, and structured layout, making it suitable for academic evaluation and portfolio use.<br>
****
**🎯 Objective**<br><br>
The main objective of this project is to:<br>
* Practice HTML semantic structure<br>
* Implement CSS layouts using Flexbox and Grid<br>
* Design a responsive and visually appealing UI<br>
* Understand real-world website structuring for businesses<br>
****
**✨ Key Features**<br><br>
* Premium dark-themed UI inspired by luxury brands<br>
* Responsive navigation bar with sticky positioning<br>
* Hero section with parallax background effect<br>
* Car inventory displayed using CSS Grid<br>
* Hover animations for interactive user experience<br>
* Forms for car selling and customer inquiries<br>
* Mobile-friendly layout using media queries<br>
****
**🛠️ Technologies Used**<br><br>
1. HTML5 --	Page structure & content<br>
2. CSS3 --	Styling, layout & responsiveness<br>
3. Google Fonts --	Typography<br>
4. Flexbox --	Navigation & layout alignment<br>
5. CSS Grid --	Inventory layout<br>
****
**▶️ How to Run the Project**<br><br>
1. Download or clone the repository<br>
2. Open the project folder<br>
3. Open index.html / website.html in any web browser<br>
   *No additional dependencies or installations required*<br>
